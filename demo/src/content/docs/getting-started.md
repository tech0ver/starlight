## Start with the template

A **consumer** is a project that uses the shared package. It supplies the pages,
navigation, glossary, diagrams, and site settings. The package supplies the
responsive reading shell, search, themes, and reusable article components.

This demo is served below the **base path** `/starlight`. The prefix is part of
links, assets, search, glossary tooltips, and the optional Markdown export.

## Follow the navigation

The sidebar keeps the tour short:

1. Read this overview to see the page shell.
2. Open [Configuration](../configuration/) to inspect one consumer setup.
3. Visit the [Feature gallery](../reading/) to try the shared content features.
4. Use the [Glossary](../glossary/) when a template term needs a precise definition.

The home page stays inside the same shell, but it is omitted from the sidebar
because the site name already links back to it.

:::do
Use the feature gallery as a quick check that the package is connected to your
consumer pages and assets.
:::

:::tradeoff
Keeping the demo small makes each extension point easy to inspect, while a real
site can add more groups and pages as its documentation grows.
:::

Continue with the [configuration guide](../configuration/) or open the
[feature gallery](../reading/).
